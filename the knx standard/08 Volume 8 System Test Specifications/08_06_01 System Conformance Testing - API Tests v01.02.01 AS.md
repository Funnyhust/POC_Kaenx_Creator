### 1 Introduction
In view of the high platform dependency of the Application Programmer’s Interface and the impossibility
to define negative test specifications, the correct implementation of declared API resides with the
applying manufacturer.

For showing compliance to a specified API, the applicant shall submit a declaration to the KNX
Association.
