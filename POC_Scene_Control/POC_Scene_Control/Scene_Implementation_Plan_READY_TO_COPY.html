1. Định Nghĩa Các Loại Action (Hành Động)

Loại Action Ý nghĩa Kỹ thuật (DPT 18.001)
None (Không dùng) Vô hiệu hóa nút nhấn / sự kiện. Thiết bị sẽ không gửi bất kỳ lệnh nào ra Bus. Không gửi Telegram
Recall (Gọi cảnh) Kích hoạt kịch bản đã lưu. Actuator sẽ chuyển trạng thái theo đúng số Scene nhận được. Gửi Byte với Bit 7 = 0
Store (Học/Lưu cảnh) Lưu trạng thái thực tế (độ sáng, vị trí rèm, On/Off) vào bộ nhớ của Actuator cho Scene đó. Gửi Byte với Bit 7 = 1

2. Chi tiết Công tắc cảnh 4 nút (Sender)

Tương tác Tham số Lựa chọn Logic gửi (DPT 18.001)
Nhấn 1 lần (Single) Action None, Recall, Store Bit 7: 0=Recall, 1=Store
Nhấn 1 lần (Single) Scene Number 0 ... 63 Bit 0..5: Scene Number
Nhấn 2 lần (Double) Action None, Recall, Store Bit 7
Nhấn 2 lần (Double) Scene Number 0 ... 63 Bit 0..5
Nhấn giữ (Long) Action None, Recall, Store Bit 7
Nhấn giữ (Long) Scene Number 0 ... 63 Bit 0..5
Logic Firmware: Lệnh gửi = (Action_Bit << 7) | (Scene_Number & 0x3F)

2. Chi tiết Actuator 4 Relay (Receiver)

Phạm vi Tham số Lựa chọn Mô tả
Global Storage Function Enable, Disable Chốt chặn toàn cục (SLME)
Slot (1-16) Scene Number 0 ... 63 ID Scene khớp với lệnh Bus để kích hoạt slot này
Slot (1-16) Relay 1..4 Action No Action, ON, OFF Trạng thái của từng relay khi gọi Scene
Slot (1-16) Storage Enable Yes, No Quyền cho phép học (SFSN) riêng cho từng slot

3. Chi tiết Bộ điều khiển rèm (Receiver)

Phạm vi Tham số Lựa chọn / Tầm Mô tả
Global Storage Function Enable, Disable Chốt chặn toàn cục (SLME)
Slot (1-10) Scene Number 0 ... 63 ID Scene khớp với lệnh Bus
Slot (1-10) Blinds Position 0 ... 100 % Vị trí rèm đích khi gọi Scene
Slot (1-10) Storage Enable Yes, No Quyền cho phép học (SFSN) riêng cho từng slot

5. Phân Tích Tác Động Bộ Nhớ (RAM & Flash)

Thiết bị RAM (Bảng Mapping + Data) Flash (NVS - Học) Flash (App - ETS)
Công tắc 4 nút ~12 Bytes 0 Bytes ~60 Bytes
Actuator 4 Relay ~49 Bytes ~33 Bytes ~120 Bytes
Bộ điều khiển rèm ~31 Bytes ~21 Bytes ~100 Bytes
Nhận xét: Việc load bảng Mapping từ Flash lên RAM là bắt buộc cho cả thiết bị gửi (Sender) và thiết bị nhận (Receiver) để đảm bảo tốc độ phản hồi lệnh tức thì (Real-time). Tổng RAM tốn thêm cực kỳ nhỏ (Dưới 100 Bytes), hoàn toàn lý tưởng và không gây áp lực lên tài nguyên chip nRF52 hay ESP32.

6. Logic Lưu Trữ (NVS)

  • Mirror RAM: Load bảng scene vào RAM khi khởi động để phản hồi Recall tức thì.
  • Write Debounce: Khi thực hiện Store (Learn), cập nhật RAM ngay và trì hoãn ghi Flash 1-2 giây để tránh ghi lặp lại liên tục gây hại Flash.
